# Project Context Index (`.index/`)

Living knowledge base for agents and humans working in this repository.

## How to use
1. At session start, read this file, then `file-inventory.md`, then `architecture.md`.
2. After any create/edit/delete, update `file-inventory.md` (and related docs).
3. Log meaningful refreshes in `context-refresh-log.md`.

## Contents
| File | Purpose |
|------|---------|
| `file-inventory.md` | Inventory of all relevant files + status |
| `architecture.md` | System overview and data flows |
| `key-decisions.md` | Lightweight ADR log |
| `dead-code.md` | Unused / legacy / dead code log |
| `context-refresh-log.md` | Index refresh history |
